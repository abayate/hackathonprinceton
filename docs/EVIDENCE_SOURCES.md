# Evidence sources and retrospective case selection

This document records the fixed selection, source findings, and quote verification for Task 014, the city-scope extension from Task 016, and the training label spot check from Task 017. It complements the original project records in [the public Texas tracker data](../data/labels/tx_projects.csv), the original four signal records in [the signal fixture](../data/signals/risk_signals.json), and the selected-candidate ledger saved with the research notes.

## Fixed selection and limits

Before source research, Task 014 froze `task-014-selection.json` with SHA-256:

`271153b07d6342bce6939ff2528841c528dd62818829c0af3d2264736a9ef0b5`

The rule selected stopped projects labeled stopped, usable for training, reliably located and carrying a stop date, excluding San Marcos, sorted by stop date descending then project ID. The first three researched cases were Matrix Data Center Campus, Project Tomahawk, and Data Factory Athens. Research was limited to about 45 minutes per project, at most eight stopped candidates, and stopped after three yielded records. The comparison cap selected a distinct nearest under-construction project with reliable coordinates from the same county where available, otherwise the nearest overall, for each of the first two stopped projects that yielded records. If both cases had selected the same project, the second would have used the next-nearest candidate. This selected Princeton Data Center (CR-559 site) for Matrix and CoreWeave Denton AI Data Center for Tomahawk. Athens’s comparison, CyrusOne Freestone Energy Center Campus, is **outside the comparison cap and was not researched**.

Five additional projects were examined: three stopped projects and two comparisons. Three of the stopped projects yielded records suitable for the fixture. Neither comparison yielded a fixture record that fits the available signal types. Across the full fixture, the evidence page now has seven rows with applicable records: Highlander SM One, the three stopped projects above, Sabey and CloudBurst with county context only, and Diode Ventures with city context only. Diode was not researched and is not a comparison case; it appears solely because its recorded city location matches the Athens ordinance added in Task 016. The two comparison projects are documented below but do not appear as case-study rows. Of the four retrospectively researched stopped cases, two have a recorded qualifying raise before a stop-type outcome and two do not; the result is descriptive and not a validation of the rule. The two without a warning differ: Matrix has a stop-type outcome with no prior raise, while Athens has no outcome record. The Task 016 city-scope extension records the Athens ordinance as context only. Area-wide context does not change the evidence rule fixed before research; allowing it to raise a project now would tune the rule to the observed results.

These cases were assembled retrospectively under the fixed selection rule. The source pages were not captured prospectively by Groundwork, and this exercise does **not** validate the evidence rule or show that an alert was live when the event occurred. The displayed model bands and dollar scenario remain unchanged. Tracker labels and statuses are reference leads only; the source wording determines each signal type.
